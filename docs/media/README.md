# Demo media

The screenshots are captures of the real v0.1.20 browser interface, using a separate synthetic `hello-codex` Git repository. They are not mockups of the native Codex sidebar.

- `../images/mogoo-codex-git-overview.png`: current browser commit graph and diff.
- `../site/assets/history-dark.webp` and `history-light.webp`: current commit views in both themes.
- `../site/assets/diff-detail.webp` and `diff-light-detail.webp`: current file-diff views.
- `quick-demo.mp4`: approximately 26 seconds, native Codex chat and Git panel, recorded with v0.1.18.
- `full-demo.mp4`: 86 seconds, native Codex chat and Git panel, recorded with v0.1.18.

The existing videos retain their real interactions and typewriter subtitles. Only their closing captions were changed to point to the installation instructions without claiming a source publication has already happened. The header remains fixed. These videos do not demonstrate a fresh installation of this v0.1.20 candidate.

All demonstration code, authors, commits, and repository data are synthetic. Source and runtime changes since the recordings are listed in [CHANGELOG.zh.md](../../CHANGELOG.zh.md).
