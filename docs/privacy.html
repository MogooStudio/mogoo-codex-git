网站统计

我们使用 Microsoft Clarity 了解访问来自哪里、哪些安装入口被点击，以及安装指令是否复制成功，帮助改进介绍和安装流程。

Clarity 还会处理页面地址、来源、设备信息及点击、滚动等交互，用于统计、热力图和页面回放。它会自动屏蔽部分敏感内容，但这不代表完全不收集数据。详情见 Microsoft 隐私声明。

本站向 Clarity 发送拒绝分析和广告 Cookie 的信号，使用不保存这些 Cookie 的受限统计模式。我们不设置自定义用户身份，也不把复制的内容作为事件数据发送。

统计仅用于这个公开官网，没有接入 Codex 插件或本机 Git 面板，不会读取你的仓库、聊天和本机文件。复制成功也不代表插件已经安装。

你可以关闭本次访问的统计并返回官网；带有该参数的页面不会加载 Clarity。浏览器发送 Global Privacy Control 信号时也会跳过统计。本说明页不加载统计。
