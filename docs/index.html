看懂之后，
再继续写。

一个本机只读面板，展开提交历史和文件差异。

01 / 提交历史

读懂提交，
顺着历史回看。

把提交之间的关系展开。分支、标签和搜索入口，让你快速找到需要查看的历史。

02 / 文件差异

变化发生在哪一行，
就在那一行看清。

从提交到文件，再到具体代码。带行号的差异，让增加、删除和修改都有清楚的位置。

自动关联仓库 / 浅色与深色 / 适配窄面板

仅在本机读取，不上传仓库。

同一段对话，
同一个仓库。

在对应的项目聊天中打开面板，就能查看这个仓库的改动。切换聊天或 worktree 后，再次调用即可。

面板只读取本机 Git 数据，不上传仓库，不执行暂存、提交或切换分支。
