# C · 工程档案台

完整桌面界面设计稿，1600 × 1000 CSS 视口。将 mogoo-codex-git 作为本地只读版本档案工具，首屏主任务是浏览提交轨迹，并阅读当前提交的文件差异。

## 方向与取舍

- 纸白、暖灰、墨黑与少量赭橙。整体采用出版物编号、精确规则线及直接排版；不使用仪表盘卡片、阴影、背景纹理或巨大标题。
- 顶部保留品牌、仓库、只读状态、刷新及三组视图 tab。历史区横向覆盖全页，以由早到新的五个线性节点交代版本脉络。
- 搜索框占用轨迹标题行中间的空区，右侧分支筛选维持紧凑 chip。master 与 origin/master 在最新提交点显示为引用标签。
- 下方以 320px 提交档案及文件目录配宽统一 diff。14 个文件、20 个差异阅读行（含 hunk 与折叠上下文提示）在 1000px 内完整出现。
- 基础界面文字 13–15px，diff 代码 13px；辅助日期、哈希和计数采用较轻等宽文字。所有文件路径均有完整 title。
- 赭橙用于当前提交与当前文件；diff 新增和删除使用独立的低饱和绿、红底色与符号，保证状态不只靠颜色辨认。

## 内容与范围

- 五个提交、作者、当前引用与 14 个文件来自给定仓库内容。文件增删数量和 plugin.json 差异通过 `git show 6b7e91f` 核对。
- 当前选中 `6b7e91f`，总变更为 +79 / −38；`codex/plugin.json` 为 +6 / −2。name、displayName、author、homepage、developerName、websiteURL 及上下文与真实差异一致。
- 聊天目录仅在底栏展示；没有仓库路径输入、提交、push、fetch、分支切换、侧边对比或 blame。
- 自包含静态 HTML/CSS，Lucide 图标为内联 SVG。搜索、tab、筛选、文件导航和刷新为完整视觉入口；搜索框允许正常输入，未接 API。未修改业务代码。
- 用户要求静态完整设计稿，未加三处动效。只保留 hover 和键盘焦点状态，避免探索稿的截图被动画状态干扰。
