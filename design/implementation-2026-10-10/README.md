# 已确认设计稿的产品实现

2026-10-10，将 Oil Git 精简稿实现为真实 React 界面。基线为 `../oil-git-reference-2026-10-10/themes/`，包括桌面与窄面板、浅色与深色。

## 交付范围

- 60px 桌面工具栏、250px 文件栏、40px 导航、430px 历史列、56px 提交行、26px 底栏；760px 时采用 44px 顶栏与 230px 历史列。
- 文件目录、提交关系、分支筛选、搜索、分页、提交详情、文件选择器、复制哈希、工作区改动、工作树与自动刷新均连接真实数据。
- 浅深色切换记住选择；存储失败仍可切换。刷新读取失败保留已有界面与选择。
- 删除原界面的统计和重复标题、独立文件详情列、仓库概览与分支常驻导航。未跟踪源文件按普通代码行显示。
- 保留当前聊天绑定、只读 API、安全文件读取、大文件/二进制/冲突提示。没有增加 Git 写操作。
- 用户要求精确还原已批准静态稿，因此不额外加入入场、主题渐变或装饰动效；仅保留真实刷新中的旋转反馈，支持 reduced-motion。

项目未配置单独的类型检查或 lint 命令。Vite 编译、浏览器实际运行与 `git diff --check` 均通过。
