# mogoo-codex-git 界面规范

以用户确认的 `oil-git-reference-2026-10-10/` 高清设计稿为基线。真实仓库的数据、计数、分支和文件必须来自 API，不能固定为稿件快照。

- 浅色背景 #fafafa / #f0f0f0，正文 #383a42，绿色 #407338；深色背景 #282c34 / #21252b，正文 #abb2bf，绿色 #98c379。语义颜色集中在 src/styles.css。
- Segoe UI / Microsoft YaHei UI；代码 Consolas / Microsoft YaHei UI，13px / 24px。提交标题 14px，列表行高 56px。
- 桌面顶栏 60px，侧栏 250px，矩形导航 40px，底栏 26px。主区使用 430px 提交列与剩余宽度的差异区。只保留一条工具栏。
- 源代码管理栏展示未暂存、已暂存、未跟踪三组，真实文件按目录展开。选中文件进入改动视图。分支与标签筛选在历史页右上角，保留全部提交选项。
- 详情依次是完整提交标题、哈希 / 作者 / 时间 / 文件数、文件选择器与统一差异。增删块与字符高亮分别配色。未跟踪文本直接按行展示，保留文件安全读取与大小限制。
- 1100px 以下收起文件栏；760px 视口采用 44px 工具栏、230px 提交列与剩余差异区，长代码软换行。改动页通过范围和文件选择器访问所有文件。600px 以下进一步改为提交与详情上下排列，保证入口可用。
- 浅深色切换使用 React 状态与 localStorage，存储不可用时仍可切换。刷新失败保留已有仓库、提交与筛选状态，并展示错误。
- 图形继续使用真实父节点算法，搜索保留关系上下文；分支节点颜色随主题调整。远端 HEAD 别名不重复显示为提交徽标，仍可在筛选中访问。
- 空仓库、无绑定目录、加载、错误、冲突、二进制、大文件和分页状态保留；不增加 Git 写操作。面板只绑定当前聊天仓库。
- 精准还原已确认的静态设计，不额外加入入场动画、主题渐变或装饰；仅保留真实刷新中的旋转反馈，并尊重 reduced-motion。
