# Git Lens 界面规范

依据 `concept.png`（内置 Image Gen 生成）实现。概念图中的仓库、提交、人员及代码仅为布局示例，产品必须显示真实读取结果，不预置演示数据。

- 背景 `#151719`，面板 `#1c1f22`，边框 `#303438`，主文字 `#e8eaec`，次文字 `#8b949e`，强调色 `#8ad4b1`。
- 使用 Segoe UI、微软雅黑与系统字体；代码使用 Consolas。标题 18～20 px，正文 13 px，辅助文字 12 px；控件明确设置字号。
- 顶栏：图标与名称、当前聊天绑定目录（只读展示）、刷新。已按用户要求移除概念图中的路径输入和“打开仓库”按钮。侧栏：仓库名、提交记录、工作区改动、工作树、本地分支、远程分支、标签。
- 主区：标题、搜索、提交表。下方：提交详情、文件列表、统一差异。页脚：只读状态、更新时间。
- 采用连续面板和细分隔线，不采用卡片网格。圆角 6～8 px，无渐变、无重阴影。图标采用 18 px 细线风格。
- 提交图必须根据真实父节点关系绘制。筛选搜索保留图的连续性，匹配行突出显示，其余行淡化。
- 小于 900 px 时压缩侧栏与元信息；小于 640 px 时折叠侧栏，保留菜单入口，详情与列表纵向排列。
- 为功能完整性补充空仓库、读取失败、加载中、文件过大、二进制文件、自动刷新开关与加载更多状态；不增加任何 Git 写操作。
