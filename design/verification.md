# 首版验证记录

这是最初界面的验证记录。后续已移除手动仓库入口并完成插件封装，当前行为及验证命令以项目 README 为准。

## 功能验证

- `pnpm test`：4 组隔离仓库集成测试全部通过。
- `pnpm build`：通过。
- `pnpm install --frozen-lockfile --offline`：通过，使用 pnpm 11.9.0。
- Codex 内置浏览器实际打开本机已有仓库，验证提交列表、单提交差异、分支筛选、搜索、清除搜索、加载至 200 条、刷新、工作区分组、未跟踪文本预览和工作树列表。
- 浏览器错误与警告日志为空。浏览真实仓库的流程没有执行 Git 写操作；完整文件哈希不变的验证在隔离测试仓库中完成。
- 默认视口 1280×720、概念图原始尺寸 1536×1024、窄面板 760×900、手机 390×844 均已查看截图。后两者页面宽度与滚动宽度一致，没有页面横向溢出；代码区自身可横向滚动。

## 视觉核对

使用 Codex 内置浏览器截图，并用 `view_image` 同时查看 `concept.png` 与本机的 `desktop.png`。没有使用外部 Playwright 回退。真实仓库验证截图仅保留在本机，不作为项目发布内容提交。

| 核对项 | 概念与实现 | 调整或说明 |
| --- | --- | --- |
| 布局 | 顶栏、左侧导航、上方提交表、下方文件和差异、底栏 | 保留同一布局与面板顺序 |
| 配色 | 炭黑背景、薄灰分隔线、青绿色选中状态 | 采用设计 token，无额外渐变 |
| 字体 | 中文系统字体与等宽代码字体 | 真实仓库标题更长，采用明确的紧凑工具字号；单行省略、悬停完整说明 |
| 图标 | 分支、历史、文件、云、标签、刷新 | 使用统一细线图标，代码原生渲染 |
| 差异展示 | 文件列表与红绿统一差异 | 去除有文本 hunk 时重复的 Git 原始头部，让首屏直接看到改动；修正对比方向文案 |
| 刷新与分页 | 保持当前选择与可见内容 | 同范围刷新和加载更多保留旧列表；查找自动定位匹配提交 |

首屏文案核对：核心导航和操作保留“Git Lens、打开仓库、刷新、提交记录、工作区改动、工作树、本地分支、远程分支、标签、只读模式”。有意补充“全部提交”、数量、当前分支、远程状态说明和自动刷新，以支撑真实仓库操作。概念图中的样例提交、作者、日期和文件由真实数据替换，不将样例作为产品数据。

当前实现保留了概念的主要结构与视觉方向；没有发现阻塞使用的布局问题。该记录不将不同仓库的数据密度或文字内容差异计为像素级还原。
